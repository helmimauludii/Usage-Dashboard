Important logic note: this prototype uses the uploaded Akamai Summary CSV for YTD tracking. The quota is set to Komdigi annual quota of 46 TB/year and converted to GB for comparison with Akamai usage. For production, the quota value should come from the customer contract table, while Akamai Scheduled Report should update the actual usage daily. If remaining quota is negative, it means the usage has exceeded the quota, but the dashboard keeps the wording as remaining quota to avoid confusion.
